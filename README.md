# Health Root NGO Website

Healthy Young People Build a Healthy Community.

Health Root NGO is a community-based organization focused on improving health awareness, youth empowerment, and community development in Rwanda.

## Features

- **Modern Rebranding**: Full site rebrand with Dark Blue, Sky Blue, and Orange palette.
- **Global Donation System**: Interactive modal supporting Credit Card and Mobile Money payments.
- **Interactive Programs**: Detailed sections for Health Education, Youth Leadership, and Environmental Protection.
- **Volunteer Integration**: Dedicated registration and call-to-action triggers.
- **Performance Optimized**: Built with Next.js 15+, using `next/image` for advanced asset loading and `framer-motion` for smooth UI transitions.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Vanilla CSS + Bootstrap Utility Classes
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
